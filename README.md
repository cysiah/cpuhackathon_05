# Heat Headroom

One-page presentation site for Forecast Factory X, Team 05 (Track 01).

Open `index.html` in a browser. No build step. The diagrams are drawn on canvas at 12 frames per second, and scrolling drives part of each one. They use the real hot-week temperatures and all 3,125 EnergyPlus sweep scores from the Atrium Heat Lab starter app, embedded in the page.
